## 1. Descrição

Criar conta com nome, e-mail e senha, aceitando os termos de uso. Origem: documento de requisitos do grupo, RF01 ([PDF](../documento-de-requisitos-mvp.pdf)).

## 2. Critérios de aceite

- [x] Dado que preencho nome, e-mail, senha forte e aceito os termos, quando clico em Continuar, então a conta é criada e vou para Interesses.
- [x] Dado uma senha sem número ou símbolo, quando envio, então vejo o erro da regra de senha forte.

## 3. Observações

A conta fica salva no navegador (localStorage); não há backend.
